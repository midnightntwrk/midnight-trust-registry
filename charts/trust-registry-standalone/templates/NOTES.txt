Bootstrap runs only node, indexer, and prover. After target-cluster genesis
readback and independent first-run approvals, supply the signed API materials
and upgrade with deploymentPhase=runtime to add API and portals.

Install only in a dedicated namespace. The default NetworkPolicy isolates
every Pod in that namespace, including unrelated Pods and actor test Pods.

This chart creates private ClusterIP Services only. It does not create Secrets,
PVCs, an Ingress, a wallet, a ledger deployment, or release approval.

All six OCI images must already exist on every eligible arm64 node because
imagePullPolicy is Never. Use an operator-labeled pod for in-namespace access:
trust-registry.midnight.network/role=operator. The operator must separately
enforce namespace RBAC so untrusted users cannot create pods with that label.
Also enforce role-label admission: Pod creators can otherwise self-assign it.

Do not claim local/offline qualification until finalized ledger readback,
egress-denied actor journeys, restart/restore, and independent security review
have been observed on the exact installed bytes.
